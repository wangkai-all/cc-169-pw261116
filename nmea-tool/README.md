# NMEA 轨迹配对台

一个**纯本地**的 NMEA-0183 文本流接收与配对网页工具：只处理 **RMC** 与 **GGA** 两类句子，
先验校验和再解析，把经纬度统一换算为十进制数值，按时间把两类句子配对成标准化轨迹点。
数据为**合成虚构轨迹**，不接入地图服务，也不需要真实定位设备。

## 运行

无需构建、无需服务器、无外部依赖：

- 直接用浏览器打开 `index.html` 即可；或
- `python3 -m http.server 8000` 后访问 `http://localhost:8000/nmea-tool/`（本目录下）。

## 处理规则（与界面页脚一致）

1. **校验和先行**：`$` 与 `*` 之间全部字符逐字节异或，与 `*` 后两位十六进制比较；不一致即拒绝，不计入后续任何处理。
2. **句型过滤**：只解析 RMC / GGA（任意 talker，如 GP/GN），其余句型（VTG、GSV…）明确忽略并计数。
3. **统一换算**：`ddmm.mmmm` → 十进制度（S/W 为负），非法范围（纬度 >90°、分 ≥60 等）拒绝。
4. **无定位分流**：RMC 状态 `V` 或 GGA 质量 `0` 的句子不参与配对，单独归类"无定位"，保留原始句与接收时间。
5. **时间配对**：RMC 与 GGA 的时间差 ≤ 配对窗口（默认 2.0s，可调）才允许配对；候选多个时取时间差最小者，并列取先到达者；严格 1 对 1。
6. **幂等**：完全相同的原始句只处理一次；位置记录 ID 由两句内容哈希决定。**重放同一段输入不会重复生成位置**（重放的句子在接入明细中标记"重复"）。

### 午夜跨日

GGA 没有日期字段。配对时以 RMC 日期为锚，在 {前一天, 当天, 后一天} 中选择使 |Δt| 最小的日期，
且必须落在配对窗口内。因此：

- 23:59:59 的 RMC 与 00:00:01 的 GGA 会跨日配对，位置正确落到**次日**；
- 00:00:01 的 RMC 与 23:59:59 的 GGA 配对时，位置留在**前一日**；
- 时间差超过窗口的历史数据**绝不会**被拼到新一天（进入待处理区）。

### 乱序到达

有效句先进入配对缓冲池，后到的对方句子到达时即配对；只要乱序跨度不超过配对窗口即可正常配对。
每当流时间推进（任一携带时间的句子到达），池中超过窗口仍未配对的句子被判定过期，移入待处理区。

### 待处理区

- **缺少日期**：GGA 在窗口内未等到 RMC，无法确定所属日期；
- **配对超时**：RMC 在窗口内未等到 GGA；
- 数据流结束（播放完成/停止）或手动"结算当前缓冲"时，池中剩余句全部结算至此。

原始句子、接收时间、未配对原因全部保留。调大窗口后点"**应用窗口并重新配对**"可对所有已接收句子
重新执行配对（派生数据整体重建，原始记录不动，因此也是幂等的）。

> 注意窗口语义：窗口大于数据周期时（如 1Hz 数据用 2s 窗口），缺口边缘的句子会按"最近邻"规则与
> 相邻历元配对（位置表中可见一串 Δt=1s 的记录）。这是窗口配对的固有行为——把窗口调到 1s 以下
> 重新配对即可消除。"缺失配对"场景专门演示了这一现象。

## 合成数据场景

轨迹为围绕虚构坐标 (30.0, 120.0) 的合成闭合曲线，含航速航向、海拔、卫星数、HDOP 等字段：

| 场景 | 演示内容 |
|---|---|
| 基础巡航 | 60 历元有序流，全部成功配对 |
| 午夜跨日 | 23:59:50 → 次日 00:00:29，含一对跨日互配 |
| 乱序到达 | GGA 先于 RMC 到达；末对 GGA 时间戳偏移 3.5s（超默认窗口，可调窗口挽回） |
| 无定位间隙 | 中段 10 秒 V/质量 0，明确归类不产生位置 |
| 缺失配对 | 单边句进入待处理区（配对超时 / 缺少日期） |
| 综合演练 | 以上全部 + 校验和错误 + 截断句 + 非目标句型 + 整段重复 |

播放控制：播放 / 暂停 / 停止 / **重放本段**（验证幂等：重放全部判重，位置数不变），速度 1×/5×/10×/瞬时。

另有**手动接收**面板：粘贴任意 NMEA 文本（每行一句）逐行接收，相同句子自动判重——粘贴同一段文本两次即可验证幂等。

## 连接模拟

- **断开**：播放中的数据被丢弃并计数（模拟真机断链丢数据）；
- **重连**：可选"补发断连期间设备缓存的数据"（乱序恢复）与"重发最近 5 秒已发送数据"（演示幂等去重）；
- 支持自动重连倒计时。

## 视图与导出

- **接入明细**：每一行的接收时刻、类型、状态（已配对/缓冲中/待处理/无定位/重复/校验错/解析错/已忽略）、原始句与备注，可按状态过滤；
- **位置表**：标准化轨迹点（UTC 时间、十进制经纬度、海拔、航速航向、卫星/HDOP、位置来源、|Δt|、配对依据）；
- **待处理区**：未配对原因与原始句；
- **轨迹图**：Canvas 等距圆柱投影，按日期分段着色（每天一段独立折线，不跨日连线），悬停查看逐点详情；
- **事件日志**：播放、断连、重连、结算、导出等操作记录；
- **导出**：轨迹 CSV / 轨迹 GeoJSON（按 UTC 排序，含配对依据）/ 接入明细 CSV（含全部原始句与接收时间）。
